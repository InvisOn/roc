# Step 6: 128-bit values as four words

## Goal

I128, U128 and Dec work. Each is four memory-resident words. Add,
subtract, bitwise ops and compares run word by word. Multiply, divide,
remainder and shifts call the same builtin wrappers as the 64-bit targets,
with each 64-bit half passed as a register pair or on the stack.

## Files from the reference snapshot

- `src/backend/dev/LirCodeGen.zig`: `generateI128BinopWords`,
  `emitI128WordChain`, `emitI128CompareWords`, `emitI128EqualWords`,
  `i128UnaryWords`, `i128StackOffset`, `emitI128FillHighWords`,
  `emitI128MulWrapWords`, `callI128WrapperWords`, the checked variants
  (`emitCheckedI128AddSubOverflow` and others), `generateNumAbsWords`,
  `generateAbsDiff128Words`, `generateBitCount128Words`, `copyStackWords`.
- Snapshots: `test/snapshots/dev_object_dec_u128.md` and its neighbours.

## Mirrors

The 64-bit targets' i128 code in the same file (`generateI128Binop`,
`getI128Parts`). That code handles two halves, this code handles four
words with the same idea.

## Holes

| Hole | Function | The concept |
|---|---|---|
| 6.1 | `emitI128WordChain` | adds then adc three times, and the same for subtraction |
| 6.2 | `emitI128CompareWords` | comparing from the top word down, signed only at the top |
| 6.3 | `i128StackOffset` | widening a word or Wide64 to 128 bits with sign or zero fill |
